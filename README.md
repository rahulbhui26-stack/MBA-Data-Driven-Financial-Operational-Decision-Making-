# Data-Driven Financial & Operational Decision-Making

**Managerial Problem-Solving Proposal | NMIMS MBA (Finance)**

An academic proposal on how a company like Yaskawa India Pvt. Ltd. can connect project finance and operations data to improve cost visibility, budget discipline and management decisions.

## Management Question

How can financial and operational information be connected to improve project-level visibility and management decisions?

## Proposed Solution

- Standardise core KPIs and reporting definitions
- Build an integrated Excel / Power BI dashboard
- Review by exception, with assigned corrective actions
